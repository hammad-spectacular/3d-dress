# dataset/clothing/

This folder is for clothing (garment) images — the items to try on.

**Target:** 20–30 clothing images across these categories:
- Shirts / tops (8–10)
- Dresses (4–6)
- Trousers / lower body (4–6)
- Jackets / outerwear (4–6)

**Where to download:**
- VITON-HD (shirts/tops): https://github.com/shadow2496/VITON-HD
- Dress Code (dresses, trousers, shirts): https://github.com/aimagelab/dress-code (requires institutional email)
- OpenVTON (various categories): https://huggingface.co/datasets/RenxingIntelligence/OpenVTON
- OmniView (jackets/outerwear): https://huggingface.co/datasets/zwpro/OmniView

**License:** All recommended datasets are non-commercial only. Personal experimentation is permitted. Do not use commercially.

**Naming:** shirt_01.jpg, dress_01.jpg, trousers_01.jpg, jacket_01.jpg, etc. (match test_pairs.json)

**Do not:** use images with unknown permissions.
