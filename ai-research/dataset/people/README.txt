# dataset/people/

This folder is for person (model) images — the target bodies onto which clothing will be tried on.

**Target:** 20–30 person images covering a variety of poses and body types.

**Where to download:**
- VITON-HD (shirts/tops focus): https://github.com/shadow2496/VITON-HD
- Dress Code (dresses, trousers, shirts): https://github.com/aimagelab/dress-code (requires institutional email)
- OpenVTON (various categories): https://huggingface.co/datasets/RenxingIntelligence/OpenVTON
- OmniView (jackets/outerwear): https://huggingface.co/datasets/zwpro/OmniView

**License:** All recommended datasets are non-commercial only (CC BY-NC or similar). Personal experimentation is permitted. Do not use commercially.

**Naming:** person_01.jpg, person_02.jpg, etc. (match test_pairs.json)

**Do not:** upload private photographs publicly, or use images with unknown permissions.
